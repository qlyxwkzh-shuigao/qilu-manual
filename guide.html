把「齐鲁会诊」装到桌面，用起来像 App

不用每次翻收藏夹、输网址。点桌面图标直接进，速度更快；之前打开过之后还能离线查看——医院网络不好的时候照样能查到会诊电话。

✅ 你已经用桌面图标打开了，无需重复添加
⚠️ 在微信里打开的同学，请先做这一步

微信内置浏览器不能直接添加。请点右上角 ⋯ → 在浏览器打开，再按下面的步骤添加。

选择你的设备

🤖
安卓手机
Chrome / Edge / 小米 / 华为 / 三星浏览器
你的设备
  1. 用浏览器打开 qiluguipei.netlify.app
  2. 点右上角 ⋮（三个点）菜单
  3. 选择 「添加到主屏幕」，部分手机显示为 「安装应用」
  4. 点 「添加」/「安装」，桌面就会出现图标
📱
iPhone / iPad
必须用 Safari 浏览器（其他浏览器不行）
你的设备
  1. 用 Safari 打开 qiluguipei.netlify.app
  2. 点屏幕底部中间的「分享」按钮 ⬆️（方框带向上箭头）
  3. 在弹出的菜单里往下滑，找到 「添加到主屏幕」 并点击
  4. 点右上角 「添加」，桌面就会出现图标
💻
电脑
Chrome / Edge 浏览器
你的设备
  1. 打开 qiluguipei.netlify.app
  2. 看地址栏右侧有没有安装小图标（⊕ 或 显示器样式的图标），有就直接点它 → 「安装」
  3. 没有图标就点右上角 ⋮ → 「安装齐鲁会诊」（或「应用」→「将此站点安装为应用」）
  4. 安装后桌面和开始菜单都会出现图标，独立窗口打开，没有地址栏，更像一个软件
💡 装到桌面之后
  • 打开更快：点图标直接进，不用每次找网址
  • 可以离线用：打开过之后手机会缓存，网络差也能查电话
  • 把常会诊的科室点 ☆ 收藏，首页会自动置顶显示
  • 桌面上找不到图标？去手机的「应用列表 / 资源库」里搜「齐鲁会诊」
  • 长按桌面图标可以拖动位置，或放进文件夹里
